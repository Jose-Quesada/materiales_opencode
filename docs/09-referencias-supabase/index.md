# 09. Referencias, esquemas y Supabase

!!! abstract "Resumen del módulo"
    Conexión de **Supabase** como base de datos real de **OpenDayCare** mediante su MCP, uso de referencias externas e internas para dar contexto preciso al agente, y desarrollo guiado por specs de tablas, autenticación en Next.js e invitación de padres.

## Puntos generales a tratar

- [ ] **Referencias externas e internas**: cómo referenciar documentos, carpetas y recursos externos eficazmente.
- [ ] **MCP de Supabase**: preparación, conexión y pruebas directas sobre la base de datos.
- [ ] **Spec e implementación de tablas**: tabla de guarderías y tabla de usuarios.
- [ ] **Conexión Next.js + Supabase**: integración de cliente, servidor y variables de entorno.
- [ ] **Login de usuarios**: especificación e implementación con Supabase Auth.
- [ ] **Gestión de niños e invitación de padres**: alta real en BD y flujo de invitación a la plataforma.
