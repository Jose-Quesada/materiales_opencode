# 06. Spec Driven Development / Design

!!! abstract "Resumen del módulo"
    Introducción y práctica de la metodología **Spec Driven Development / Design (SDD)** apoyada en **Agent Skills**, construyendo mecánicas de un juego estilo Pac-Man mediante especificaciones previas y flujo con Pull Requests.

## Puntos generales a tratar

- [ ] **Fundamentos y consideraciones de SDD**: por qué especificar antes de implementar reduce errores y retrabajo.
- [ ] **Agent Skills**: qué son, cómo se instalan y cómo preparan el proyecto.
- [ ] **Flujo de trabajo con Git**: bloqueo de rama principal e integración mediante Pull Requests.
- [ ] **Ciclo Spec → Implementación**: casos prácticos (fantasmas, corrección de punto de salida, *Power Pellets*).
