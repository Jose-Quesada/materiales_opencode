# 05. Worktrees y comandos personalizados

!!! abstract "Resumen del módulo"
    Uso de **Git Worktrees** para trabajar múltiples funcionalidades en paralelo sin interferencias, creación de **comandos personalizados** en OpenCode e integración directa con **GitHub** (issues y cambios en la nube).

## Puntos generales a tratar

- [ ] **Proyecto práctico (*Asteroids*)**: base del juego para experimentar con ramas paralelas.
- [ ] **Git Worktrees (manual y automático)**: creación, prueba por árbol aislado y fusión.
- [ ] **Comandos personalizados en OpenCode**: creación de atajos reutilizables para tareas frecuentes.
- [ ] **Integración OpenCode + GitHub**: conexión con repositorios, issues y flujos en la nube.
- [ ] **Instrucciones personalizadas y privilegios**: control de permisos y formato automático de issues.
