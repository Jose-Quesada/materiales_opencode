# 07. MCPs y Agentes personalizados

!!! abstract "Resumen del módulo"
    Arranque del proyecto principal **OpenDayCare** integrando servidores **MCP (Model Context Protocol)** como Playwright y Context7, skills personalizadas (`spec` y `spec-impl`) y un agente verificador (**Spec Verifier**) con criterios de aceptación automáticos.

## Puntos generales a tratar

- [ ] **Inicio de proyecto (*OpenDayCare*)**: contexto, arquitectura base y objetivos.
- [ ] **MCP Playwright**: automatización y verificación visual/funcional en navegador.
- [ ] **MCP Context7**: consulta de documentación actualizada de librerías y frameworks.
- [ ] **Skills `spec` y `spec-impl`**: estandarización de especificaciones e implementaciones.
- [ ] **Agente personalizado *Spec Verifier***: validación automática de criterios de aceptación.
- [ ] **Implementación de features**: *HomePage*, pantalla de niños y perfil.
