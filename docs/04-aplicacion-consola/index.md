# 04. Aplicación de consola

!!! abstract "Resumen del módulo"
    Aplicación práctica de OpenCode construyendo desde cero una **Weather App** de consola: definición de contexto en `Agents.md`, iteración sobre mejoras (colores, pronóstico, estructura), pruebas automáticas y flujo de CI/CD con GitHub Actions.

## Puntos generales a tratar

- [ ] **Inicio de proyecto (*Weather App*)**: definición de requisitos y estructura inicial.
- [ ] **Configuración de `Agents.md`**: reglas y contexto del proyecto para guiar al agente.
- [ ] **Planeación y construcción**: flujo iterativo con OpenCode para generar la aplicación.
- [ ] **Ideas, problemas y ajustes**: detección de fallos y refinamiento asistido.
- [ ] **Mejoras prácticas**: colores en terminal, pronóstico extendido y organización de archivos.
- [ ] **Pruebas automáticas**: validación del comportamiento de la CLI mediante tests.
- [ ] **GitHub Actions**: automatización de *builds* y *release tags*.
