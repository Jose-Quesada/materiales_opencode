# 01. Introducción

!!! abstract "Resumen del módulo"
    Módulo inicial orientado a presentar la estructura del curso, la forma de aprovechar las clases, cómo resolver dudas y dejar listas las herramientas base antes de instalar y configurar OpenCode.

## Guías del módulo

| Guía | Contenido principal |
| :--- | :--- |
| [1. Conceptos básicos de IA para clase](01-fundamentos-ia.md) | Cómo funcionan los LLMs, **tokens**, **ventana de contexto**, modelos *stateless* y "zona tonta", *prompts*, diferencia entre **modelo / proveedor / API Key / agente**, **comparativa de modelos y costos (OpenAI, Anthropic, Gemini, DeepSeek, Qwen)**, **modelos de toma de decisiones (JEV vs LLM)**, alucinaciones y glosario exprés. |

## Puntos generales a tratar

- [x] **Fundamentos de IA para clase**: vocabulario esencial (*LLM*, *token*, *contexto*, *prompt*, *agente*, *alucinación*) antes de instalar OpenCode.
- [ ] **Bienvenida y objetivos del curso**: alcance de OpenCode en el flujo real de desarrollo de software.
- [ ] **Dinámica del curso**: cómo seguir las sesiones, tareas prácticas y repositorios.
- [ ] **Resolución de dudas**: buenas prácticas para formular preguntas efectivas.
- [ ] **Instalaciones previas**: requisitos del sistema y herramientas necesarias antes de empezar.
- [ ] **Comunidad**: acceso al servidor de Discord de DevTalles.
