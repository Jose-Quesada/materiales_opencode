# 12. Producción

!!! abstract "Resumen del módulo"
    Paso a producción completo del proyecto **OpenDayCare**: preparación de build y variables, aprovisionamiento de la base de datos productiva, despliegue en **Vercel**, migración de esquemas y usuarios, y verificación final en entorno real.

## Puntos generales a tratar

- [ ] **Preparación para el despliegue**: revisión de variables de entorno, builds y seguridad.
- [ ] **Aprovisionar base de datos en producción**: creación y configuración del entorno productivo en Supabase.
- [ ] **Vercel — Configurar producción**: conexión del repositorio, secretos y despliegue.
- [ ] **Migrar base de datos y usuarios**: traslado limpio de estructura y datos iniciales.
- [ ] **Revisar y probar en Producción**: smoke tests y validación de flujos críticos en vivo.
