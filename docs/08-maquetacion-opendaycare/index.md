# 08. Maquetación de OpenDayCare

!!! abstract "Resumen del módulo"
    Continuación de la maquetación y desarrollo funcional de **OpenDayCare**, incorporando comandos personalizados para dar continuidad al proyecto, flujos de autenticación y gestión de niños/padres, además de integrar el agente de verificación con GitHub.

## Puntos generales a tratar

- [ ] **Configuración de comandos**: atajos para mantener continuidad entre sesiones.
- [ ] **Login y activación de cuenta**: maquetación y flujo de acceso.
- [ ] **Agregar niños al sistema**: interfaz y validación del alta de niños.
- [ ] **GitHub + OpenCode**: revisión de especificaciones y aplicación de feedback en PRs.
- [ ] **Vincular padre y nueva publicación**: flujos principales de interacción en la plataforma.
