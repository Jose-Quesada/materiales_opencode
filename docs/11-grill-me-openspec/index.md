# 11. Metodologías Grill Me y OpenSpec

!!! abstract "Resumen del módulo"
    Exploración práctica de metodologías complementarias para elevar la calidad de las especificaciones: **Grill Me** (cuestionamiento profundo previo al diseño) y **OpenSpec** (flujo estructurado de ciclo de vida de especificaciones).

## Puntos generales a tratar

- [ ] **Metodología *Grill Me***: cómo usar entrevistas críticas con el agente para detectar ambigüedades antes de escribir código.
- [ ] **Grill Me + SDD**: aplicación práctica en la creación de posts dentro de *OpenDayCare*.
- [ ] **OpenSpec — Instalación y configuración**: puesta en marcha en el proyecto.
- [ ] **Ciclo de trabajo en OpenSpec**:
    - [ ] `Explore` y `New`
    - [ ] `Apply`
    - [ ] `Verify`
    - [ ] `Archive`
