# 10. Automatizaciones y agentes en paralelo

!!! abstract "Resumen del módulo"
    Automatización de tareas de desarrollo mediante **agentes especializados en paralelo**, formateadores automáticos para mantener consistencia en el código y **CRON Jobs** para ejecución autónoma sin intervención manual.

## Puntos generales a tratar

- [ ] **Formateadores**: configuración para normalizar automáticamente el código generado por agentes.
- [ ] **Criterio de uso de agentes**: cuándo y para qué tareas conviene delegar en agentes especializados.
- [ ] **Agentes especializados**:
    - [ ] Mejores prácticas en React
    - [ ] DB Migrator
    - [ ] Accessibility Checker
    - [ ] Auditor de base de datos
- [ ] **Invocación semi-manual vs. automática**: niveles de control, supervisión y paralelismo.
- [ ] **CRON Jobs**: programación de ejecuciones periódicas autónomas.
